<objective>
Close the two configuration questions this phase opens before any integration fixture can run:
where the test database URL comes from (D-04), and how the only non-async port of Phase 2 —
`Clock` — gets its runtime adapter.

mappers and repositories (plans 03-04 onward) stamp entities with `SystemClock`.

| Boundary | Description |
|----------|-------------|
| process environment → `Settings` | `DATABASE_URL`, `TEST_DATABASE_URL` and `JWT_SECRET` cross here; a wrong or defaulted value is a security event, not a convenience |
| `.env.example` (tracked) → `.env` (untracked) | The example file is public; it must never hold a real credential |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-3-10 | Information disclosure | `database_url.py` | mitigate | `hide_password=False` appears only where a live connection string is produced, with an inline comment forbidding it in any message; every URL printed to a human uses the masking default (enforced again in plan 03-05's fail-fast fixture) |
