02-04 TDD RED/GREEN capture
===========================

Why this file exists
--------------------
Plans 02-01, 02-02 and 02-03 hit the same wall and established the convention this
file follows: a RED commit cannot stand on its own in this repository. The
`mypy (strict)` pre-commit hook type-checks `src` and `tests` on every commit and
rejects a test (or a probe script) importing a module that does not exist yet, and
CLAUDE.md forbids `--no-verify`. So the RED step is executed for real, captured here
verbatim, and committed alongside the code that turns it green.

Everything below is copied from the terminal, not retyped.
