<objective>
Build the single exception-handling point: one `problem()` body builder, one class-to-status
table, four handlers registered from `create_app()`, and a throwaway probe router that
proves all of it end to end before any real route exists.

Purpose: ARC-07 and roadmap success criterion 4 - the error contract must be demonstrably
in place *before* the first real router, because every Phase 4/5 endpoint depends on it and
none of them should ever build an error body. Three of the shapes here have a non-obvious
failure mode that was reproduced during research: mypy rejects the natural handler
signature, `ServerErrorMiddleware` always re-raises so the 500 test needs its own client,
and a custom `HTTPException` handler silently drops `WWW-Authenticate` and `Allow`.
Output: `presentation/api/errors/{problem,mapping,handlers}.py`, the `create_app()` wiring,
`tests/{conftest,probe}.py` and `tests/api/test_error_contract.py`.
</objective>
