What this proves: D-15's gate is enforced rather than decorative, and its two
assertions are not redundant. Plant 1 turns BOTH red. Plant 2 - a module that
merely imports the class and never raises it - leaves the raise check GREEN and
turns only the import check red, which is the whole case for keeping the second
assertion: the raise check cannot see a construction bound to a local name, and
the import check makes that spelling impossible in the first place.

The plants were removed immediately after the red runs. They exist neither on
disk nor in git history as tracked changes; the green run at the bottom is the
shipped tree. Everything below is verbatim, exit codes included.

The one edit applied to the captures below: the repository's trailing-whitespace
pre-commit hook stripped the trailing spaces pytest pads its assertion-diff lines
with. No line was added, removed or reworded, and no exit code changed.
