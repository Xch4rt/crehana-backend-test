    mutable through the frozen wrapper.

    number describes the list. `completion_percentage` is `0.0` for an empty list because
    `CompletionStats.percentage` returns `0.0` when `total == 0`, so no division guard belongs here.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request body → application command | The command is the first typed representation of what a client asked for |
| domain entity → result DTO | The result is what the public API is allowed to see; a field added here is a field published |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-17 | Elevation of privilege | mass assignment through a PATCH command | mitigate | `UpdateTaskCommand` declares no `status`, no `owner_id`, no `assignee_id` and no `completed_at`; an acceptance criterion asserts `status` is absent from its field set, so a later edit that adds it fails a gate (D-08) |
| T-4-18 | Tampering | `actor_id` supplied by the client | mitigate | `actor_id` is the first field of every command and is filled by the presentation dependency, never from a body or a path; a field-order test enforces the convention mechanically |
| T-4-19 | Information disclosure | an entity field leaking into a response by accretion | mitigate | `from_entity` names every field; a `from_entity` test asserting the full field list fails when the result and the entity drift apart |
| T-4-20 | Tampering | a mutable result crossing the layer boundary | mitigate | `frozen=True, slots=True` on both new results, with `items` a tuple rather than a list; `FrozenInstanceError` and `__slots__` tests per class |
| T-4-21 | Information disclosure | a wrong completion percentage presented as fact | mitigate | The percentage is read from `CompletionStats.percentage`, which Phase 2 already tested; the 2-of-3 → `66.67` and empty → `0.0` cases are pinned here so a later "improvement" to the rounding fails a test |
| T-4-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no package |
</threat_model>
