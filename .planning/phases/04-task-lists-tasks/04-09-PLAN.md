     the full stack is ['SAVEPOINT', 'SELECT', 'ROLLBACK'], so the filter is not optional. -->

```python
@pytest.fixture
def statements(connection: AsyncConnection) -> Iterator[list[str]]:
    seen: list[str] = []

    def record(conn, cursor, statement, parameters, context, executemany):
        verb = statement.split(maxsplit=1)[0].upper()
        if verb in {"SELECT", "INSERT", "UPDATE", "DELETE"}:
            seen.append(verb)

    event.listen(connection.sync_connection, "before_cursor_execute", record)
    try:
        yield seen
    finally:
        event.remove(connection.sync_connection, "before_cursor_execute", record)
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| second actor → another owner's resources | The only place the cross-tenant claim can be tested as a client experiences it |
| error body → client | What a refusal reveals is part of the attack surface |
| test isolation → truthfulness of the suite | A fixture that leaks rows makes later assertions meaningless |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-51 | Elevation of privilege | IDOR across owners over HTTP | mitigate | One not-owned test per verb using `dependency_overrides[get_current_actor]`, each asserting the body is identical to the absent-resource body apart from `instance` (D-04, ASVS V4) |
| T-4-52 | Information disclosure | a distinguishable 404 revealing that a foreign list exists | mitigate | The tests compare the two problem bodies rather than only their status codes, which is the only assertion that can catch a difference in `code`, `detail` or `errors` |
| T-4-53 | Information disclosure | client input echoed in an error body | mitigate | A dedicated test posts a marker string, triggers the refusal and asserts the marker is absent from the serialised body |
| T-4-54 | Elevation of privilege | mass assignment accepted silently | mitigate | The unknown-key 422 test proves `extra="forbid"` reaches the client as `extra_forbidden` at the named field rather than being ignored (D-06) |
| T-4-55 | Repudiation | a test suite whose rows leak between tests | mitigate | The harness reuses the Phase 3 `connection` fixture's outer rollback; seeding sessions `commit()` into it rather than around it, and no test truncates a table |
| T-4-56 | Tampering | a deprecated test client re-entering the suite | mitigate | `filterwarnings = error` makes the import itself fail; `grep -rc "TestClient" tests/` printing `0` is an acceptance criterion |
| T-4-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no package |
</threat_model>
