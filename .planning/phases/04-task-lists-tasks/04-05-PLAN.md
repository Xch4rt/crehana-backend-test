```python
class ChangeTaskStatus:
    def __init__(self, uow: UnitOfWork, clock: Clock) -> None:
        self._uow = uow
        self._clock = clock

    async def execute(self, command: ChangeTaskStatusCommand) -> TaskResult:
        async with self._uow:
            task = await visible_task(self._uow, command.task_list_id,
                                      command.task_id, command.actor_id)
            task.change_status(command.new_status, now=self._clock.now())
            await self._uow.tasks.update(task)
            await self._uow.commit()
        return TaskResult.from_entity(task)
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command → visibility decision | The use case is the only place that decides what an actor may see (ADR-008) |
| command → domain mutator | Business limits belong to the entity; the use case must not re-validate or bypass them |
| transaction boundary | The use case owns `commit()`; a refusal must leave nothing durable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-22 | Elevation of privilege | cross-tenant read, update or delete of a task list | mitigate | Every verb loads through `visible_task_list`; a two-actor unit test per verb asserts `TaskListNotFoundError` with `details` identical to the absent-list case (D-04, ASVS V4) |
| T-4-23 | Information disclosure | another owner's list appearing in the collection | mitigate | `ListTaskLists` reads only `list_for_owner_with_stats(actor_id)`, whose SQL scope was proved in plan 04-02; a unit test asserts a foreign list never appears |
| T-4-24 | Denial of service | N+1 on the index endpoint | mitigate | One repository call for the whole collection, plus a unit-level assertion that `completion_stats` is called zero times during `ListTaskLists` |
| T-4-25 | Tampering | a duplicate name slipping past under concurrency | mitigate | The pre-check gives the clean 409; `uq_task_lists_owner_id_name` and the adapter's `IntegrityError` translation remain the authority, and the comment says so rather than presenting the pre-check as the guard |
| T-4-26 | Repudiation | a refused write that still commits | mitigate | Every failure test asserts `commits == 0` and `rollbacks == 1`; every success test asserts the mirror image |
| T-4-27 | Elevation of privilege | `owner_id` taken from the request instead of the actor | mitigate | `TaskList.create` is called with `owner_id=command.actor_id`; `CreateTaskListCommand` has no owner field at all, so there is nothing else it could be |
| T-4-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no package |
