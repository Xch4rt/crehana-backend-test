Threshold: --cov-fail-under=75, declared in pytest.ini addopts

Why this file exists: a coverage gate that has never been seen failing is
indistinguishable from a no-op. The run below adds one 16-statement module,
src/taskmanager/infrastructure/_coverage_probe.py, that NO test imports, and
the gate drops the total to 40.91% and exits non-zero. That an un-imported
module lands in the denominator at all is the direct payoff of configuring
coverage as source = ["taskmanager"] (the installed package name) rather than
as a filesystem path: a path-based source only measures files that were
actually imported, so dead modules would silently never be counted.

The probe was deleted immediately after the red run and does not exist in the
repository; the green run below is the same command on the shipped tree.
