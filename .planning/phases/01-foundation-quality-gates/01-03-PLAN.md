Contents, section by section:

`[importlinter]` with `root_package = taskmanager` and `include_external_packages = True`.
The latter is required for any `forbidden` contract that names a third-party
distribution — without it the forbidden contracts cannot see `fastapi` at all.

`[importlinter:contract:layers]` with `name = Layered architecture (high to low)`,
`type = layers`, and `layers` listing, one per line highest first:
`taskmanager.main`, `taskmanager.presentation`, `taskmanager.infrastructure`,
`taskmanager.application`, `taskmanager.domain` (D-10 order, verbatim).

`[importlinter:contract:domain-framework-free]` with
`name = Domain is framework-free`, `type = forbidden`,
`source_modules = taskmanager.domain`, and `forbidden_modules` listing `fastapi`,
`starlette`, `sqlalchemy`, `alembic`, `pydantic`, `pydantic_settings`, `jwt`, `pwdlib`,
`httpx`. `pydantic` is forbidden here because the domain uses stdlib dataclasses only.

`[importlinter:contract:application-framework-free]` with
`name = Application knows no web framework or ORM`, `type = forbidden`,
`source_modules = taskmanager.application`, and `forbidden_modules` listing `fastapi`,
`starlette`, `sqlalchemy`, `alembic`, `jwt`, `pwdlib`. `pydantic` is deliberately absent
from this list: application DTOs are Pydantic models.

Do NOT add the fourth contract restricting `presentation.api.routers` / `.schemas` from
importing `infrastructure`. Those modules do not exist until Phase 3 and import-linter
errors on unresolvable `source_modules`. Phase 3 adds it.

Get the section header prefix exactly right: `[importlinter:contract:...]` — singular
`contract`. The plural typo `[importlinter:contracts:...]` yields a configuration with
zero contracts, which import-linter reports as "0 kept, 0 broken" and exits 0
(RESEARCH Pitfall 2). Task 2's guard test is what catches that, but do not rely on it.

Finally run `.venv/bin/lint-imports` and confirm it exits 0 AND that its output names all
three contracts. Output that never mentions the contract names is the warning sign of the
zero-contract silent pass.
