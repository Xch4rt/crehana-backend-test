|----------|-------------|

| Working tree → Docker build context | Anything not excluded is readable in an image layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `.env` in the working tree | mitigate | `.env` listed in `.gitignore` (Task 3) and in `.dockerignore` (Task 3); acceptance criteria assert both |
| T-01-02 | Information Disclosure | `.git`, `.planning` in the Docker build context | mitigate | `.dockerignore` excludes `.git`, `.github` and `.planning` before any Dockerfile exists (Task 3) |
| T-01-SC | Tampering | pip installs from `requirements*.txt` | mitigate | All 28 packages carry a `slopcheck` `[OK]` verdict in RESEARCH § "Package Legitimacy Audit" (28/28, 0 `[SUS]`, 0 `[SLOP]`); versions are exact `==` pins taken verbatim from that audited list. No `[ASSUMED]`/`[SUS]` package exists, so no blocking human checkpoint is required |
| T-01-03 | Tampering | version drift between `pyproject.toml` and `requirements*.txt` | mitigate | `[project.dependencies]` is deliberately absent (Task 1); a single source of truth cannot disagree with itself |
| T-01-04 | Repudiation | a lint gate that reports green because its config silently reset the defaults | mitigate | `.flake8` uses `extend-ignore`/`extend-exclude` only; Task 2 verification asserts the bare forms are absent |
