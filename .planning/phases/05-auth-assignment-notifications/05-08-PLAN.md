<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated caller → someone else's task | `PUT .../assignee` is the phase's new write path and its new IDOR surface |
| caller-supplied `assignee_id` → a user lookup | An id the caller invented, used to probe whether a user exists |
| committed transaction → an outbound side effect | The notification must be unable to influence what was already made durable |

## STRIDE Threat Register
