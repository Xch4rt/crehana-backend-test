      - It does **not** call `_refuse_nul`. A password never becomes a text column — only the Argon2
        encoded hash is stored, and Argon2 hashes arbitrary bytes — so the NUL guard that protects
        `title`, `name` and `full_name` has nothing to protect here, and adding it would be a
        composition rule D-10 rules out.

        plaintext at all (Phase 2 D-04 puts the limit in the domain, and this is the only place in

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied password → the hashing adapter | The first Phase 5 value that crosses from an untrusted body into an expensive computation |
| operator-supplied `JWT_SECRET` → token signing | A boot-time value that decides whether every issued token is forgeable |
| caller-supplied `assignee_id` → the task aggregate | The mutation ASGN-01 exposes to the list owner |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-02 | Spoofing | `Settings.jwt_secret` | mitigate | `Field(min_length=32)` refuses a key RFC 7518 §3.2 calls too short for HS256; the field still has no default at all, so a missing value is a boot failure; `test_short_secret_is_rejected` pins the boundary at 31/32 |
| T-5-07 | Denial of service | Argon2 over an unbounded password | mitigate | `require_password`'s 128-character cap is validated in the domain before any hashing adapter is reached; the floor and the cap are module constants spelled once, so no call site can widen them |
| T-5-03 | Information disclosure | a secret gaining a default or an example value that works | mitigate | `.env.example` documents a generation command rather than a usable credential, and no default is added in code; `test_env_example_documents_every_field` keeps the documented set and the declared set equal |
| T-5-13 | Tampering | control characters in a credential | accept | `require_password` deliberately does not refuse NUL: the plaintext never becomes a text column, only its Argon2 hash is stored. Recorded as a decision in the function's docstring rather than left implicit |
| T-4-03 | Tampering | half-applied mutation on a refused `assign` / `unassign` | mitigate | `require_utc` runs before the first assignment, copied from `rename`, whose comment records the defect; two negative tests assert both `assignee_id` and `updated_at` are unchanged after a refusal |
| T-5-SC | Tampering | pip installs | accept | This plan installs no package. `05-RESEARCH.md` § Package Legitimacy Audit re-checked the four auth-relevant packages already pinned (`slopcheck`: 4 scanned, 4 OK); `requirements*.txt` are unchanged by this plan |
</threat_model>
