      - **`GET /users` as an email directory** (D-13). Options: scope to a tenancy the brief has no

        caller can read every address — and that is also the bound that makes D-08's
        `user_not_found` 404 disclose nothing to an owner.

        CONTEXT's "the ports keep their shape". Options: a module-level dummy hash in the use case

        method. Measured: 23.4 ms vs 23.6 ms.
      - **PyJWT decode policy**: `algorithms` pinned from settings (RFC 8725 §2.1), `require`
        `sub`/`exp`/`iat`, `leeway=0`, and `InvalidKeyError` deliberately outside the catch so a
        misconfigured server is a 500 rather than a 401 blaming the caller.
      - **`anyio.to_thread` over `asyncio.to_thread`**, and why `anyio` is imported without its own
        exact pin — it is a hard transitive of Starlette, which `fastapi==0.141.1` pins. Record the

      - **The package-wide JSON log handler** (D-15, D-24). uvicorn configures only `uvicorn*` and
        leaves root at WARNING, so the INFO line was dropped entirely — verified by execution.
        Options: a `--log-config` file (untested, outside coverage, does nothing for `caplog`), a
        handler on `taskmanager.notifications` only, a handler on the package. Consequence: the
        existing 500 record is now JSON too, which is a visible change to existing behaviour.
      - **Register's 409 is an enumeration oracle, conceded not mitigated** (D-23, T-5-06). Say
        plainly: AUTH-01 requires the 409, the requirement was chosen over the property, and here is
        the bound on the damage — the error carries no address, and `GET /users` already discloses
        every address to authenticated callers, so the residual leak is to unauthenticated ones.
      - **No login rate limiting** (T-5-08). Not mitigated, explicitly deferred; Argon2's ~25 ms
        floor is an incidental throttle, not a control. Owed to Phase 7's README future-work list.
      - **`jwt_secret`'s floor moved 16 → 32** (D-26), naming RFC 7518 §3.2 and the interaction with
        `filterwarnings = error`.
      - **The harness split and the new statement counts** (D-20). `api_client` keeps its override so
