## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| every role → every route | The complete cross-product, which is the only honest shape for an authorization claim |
| an empty volume → a running API | First-run behaviour is where a missing migration or a deleted seed shows up |
| container stdout → an evaluator | The log line is the only visible evidence the notification happened |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-11 | Information disclosure / Tampering | IDOR anywhere in the API | mitigate | All 76 cells asserted, with the covered route set compared against `app.openapi()["paths"]` so an unmeasured route is a failure; every 403 and 404 cell asserts the body's `code`, not only the status |
| AUTH-03 | Spoofing | a route reachable without a token | mitigate | The anonymous column covers all 19 rows against the real dependency, and the three open rows are asserted **open** rather than skipped, so "which routes are unauthenticated" is stated by the table |
| T-5-15 | Spoofing | a stale token accepted after a role change | mitigate | Every authenticated cell mints its token for a seeded row through the real dependency, which confirms the row on each request |
| T-5-03 | Information disclosure | a shipped credential | mitigate | The cold start proves the stack begins with zero users; the rehearsal's password exists only in the transcript, and the capture is checked for the absence of any seed statement |
| NOTF-02 | Repudiation | a notification claimed but never emitted | mitigate | The capture contains the real `docker compose logs api | grep task_assigned_email` output, parsed as JSON, rather than a claim that it would appear |
| T-5-13 | Tampering | log injection | mitigate | Plan 05-06 and plan 05-14 own the proof; this capture additionally shows the line is one parseable JSON object in the real container's stdout |
| T-5-SC | Tampering | pip installs | accept | This plan installs no package. `docker compose down -v` affects only this project's stack, and the task ends by proving `taskmanager_test` is reachable again |
