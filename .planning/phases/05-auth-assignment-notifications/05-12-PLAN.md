<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated caller → the user directory | Every address in the system is readable by anyone with a token |
| authenticated caller → someone else's task assignment | The new write door, and the phase's new IDOR surface |
| the OpenAPI document → an integrator | An undocumented 401 or 403 is a client that handles neither |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-11 | Information disclosure / Tampering | IDOR through the three new routes | mitigate | Both assignee verbs go through `owned_task(..., for_update=True)` in the use case; `assigned-to-me` filters on the token's subject with no client-supplied id anywhere in its signature; plan 05-15's matrix walks all three |
| T-5-12 | Information disclosure | user-existence oracle through `PUT .../assignee` | mitigate | Ordering is enforced in the use case (plan 05-08), and the route description states that the `user_not_found` 404 is reachable only by an owner, who can already call `GET /users` |
| T-5-06 | Information disclosure | `GET /users` as an email directory | **accept** (D-13) | Readable by any authenticated caller, by requirement (ASGN-03). Stated in the route description rather than hidden; ADR owed in plan 05-16; the bound is that it is authenticated-only |
| T-5-10 | Tampering | assignment smuggled through another verb | mitigate | Assignment has its own door and its own schema; the task create and patch bodies refuse `assignee_id` as exactly one `extra_forbidden` error (plan 05-09) |
| T-5-08 | Denial of service | an unbounded collection | accept | No pagination, by ADR-043, on a deliverable whose data set is whatever an evaluator creates in five minutes. Listed as future work in Phase 7's README |
| AUTH-03 | Spoofing | a route that answers without a token | mitigate | The 19-operation partition assertion: every operation outside the three named open ones declares a 401 **and** carries a `security` array |
| ADR-051 | Tampering | `HTTPException` in a new router | mitigate | Both new modules join `REQUIRED_SCANNED_MODULES` in the commits that create them; the AST gate refuses the import as well as the raise |
| T-5-SC | Tampering | pip installs | accept | This plan installs no package |
</threat_model>
